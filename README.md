# Executive Summary Dashboard - Power BI

## 📌 Project Overview
This project is an end-to-end Business Intelligence solution built using Microsoft Power BI. It transforms raw business data into an interactive Executive Summary Dashboard to analyze sales performance, regional distributions, and customer purchasing patterns.

## 🛠️ Key Steps & Workflow
1. **Data Ingestion & Cleaning:**
   - Imported raw data into Power BI.
   - Handled null values, data types, and transformations using **Power Query**.

2. **Data Modeling:**
   - Created relationships between fact and dimension tables.
   - Built a custom **Date Table** for time-intelligence capabilities.

3. **DAX Calculations:**
   - Authored custom measures for metrics like **Gross Sales**, **Net Sales**, **Total Profit**, and **Total Orders**.

4. **Visualizations & Insights:**
   - **KPI Cards:** Topline summary for fast executive review.
   - **Monthly Trends:** Tracking sales trajectories over time.
   - **Category & Regional Insights:** Breakdowns across business segments and geographic zones.
   - **Store & Payment Distribution:** Deep dives into payment channels (UPI, Card, Cash) and store formats.

---

## 💻 Tech Stack
- **Tool:** Microsoft Power BI Desktop
- **ETL:** Power Query
- **Calculations:** DAX (Data Analysis Expression)
